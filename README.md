### 💻 Proyectos destacados

#### 🃏 [La Escoba — Motor de Juego y Persistencia en Java](https://github.com/TU-USUARIO/la-escoba-java)
*Tecnologías para el Desarrollo de Software · UVa*  
Implementación de la lógica del juego de cartas La Escoba (baraja española de 40 cartas) desarrollada bajo metodología **TDD**. Incluye jerarquía de dominio (`Partida`, `Ronda`, `Turno`, `Jugada`), modo multijugador, persistencia con **Hibernate** sobre HSQLDB, suite de tests unitarios y de integración (**JUnit 5**, mocks, **DBUnit**), pipeline CI/CD y refactorizaciones guiadas por **SonarQube**.  
`Java` · `Hibernate` · `JUnit 5` · `TDD` · `Maven` · `SonarQube`

#### 🌐 [MenInf — Plataforma Web de Recomendación de Menciones](https://github.com/TU-USUARIO/MenInf)
*Servicios y Sistemas Web · UVa*  
Aplicación web full-stack diseñada para orientar a estudiantes de Ingeniería Informática en la elección de su mención de tercer curso y optativas a partir de un formulario de afinidad académica. Desarrollada bajo arquitectura **MVC** con Servlets, JSP, patrón DAO y pool de conexiones sobre **MariaDB**.  
`Java` · `Jakarta EE` · `Servlets / JSP` · `MariaDB` · `JavaScript` · `Maven`

#### 📞 [TCONN-ACME — Sistema de Gestión de Incidencias y Soporte Técnico](https://github.com/TU-USUARIO/tconn-acme)
*Diseño de Software · UVa*  
Aplicación de escritorio para la gestión integral de atención telefónica, control de disponibilidad de técnicos y seguimiento de incidencias en una operadora de telecomunicaciones. Modelada en **UML** y desarrollada bajo arquitectura en cuatro capas (Swing, controladores de caso de uso, DAOs y JDBC sobre **PostgreSQL**) con scripts SQL de pruebas por caso de uso.  
`Java` · `Java Swing` · `PostgreSQL` · `JDBC` · `UML` · `Maven`
